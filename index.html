Fresher Job Watcher

Open source · MIT
Stack
Python · REST APIs · GitHub Actions (CI/CD) · Telegram Bot API
Source
github.com/krishkumar6/fresher-job-watcher
  • Polls the public REST APIs of five applicant-tracking systems (Greenhouse, Lever, Ashby, SmartRecruiters, Workday) across 129 companies and pushes new fresher openings to Telegram within two hours — serverless on a GitHub Actions cron, at zero cost.
  • Designed a three-stage filter (title keywords, regex experience parsing of full descriptions, stack matching) that fails open when a requirement can't be verified, fetching descriptions only for new matches to hold each run under five minutes.
  • Engineered durable state: a committed JSON seen-jobs store, a first-run baseline preventing alert floods, failed sends retried on the next run, and a weekly health check that files a GitHub issue when a board goes stale instead of failing silently.

Rental Agreement Intelligence Assistant

RAG · LLM agent
Stack
Python · FastAPI · SQLAlchemy · ChromaDB · Hugging Face · Groq · BeautifulSoup · Pydantic
Source
github.com/krishkumar6/rental-assistance
  • Built a FastAPI backend that scrapes listing data with BeautifulSoup and extracts structured lease fields (rent, deposit, dates, pet policy) from raw text using an LLM in JSON mode, validated with Pydantic and persisted via SQLAlchemy.
